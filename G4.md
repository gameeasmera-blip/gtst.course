# sudo:

mirga kompiutara bulchuu (Administrative / Root Privileges) haala safee fi seeraan deeggarameen tajaajiltootaaf kennuu dha.
Nageenya Kompiutaraa Eeguu (Security & Protection)
Pakeejota fi Porogiraamota Fooramsuu / Haaraomsuu (Installing & Updating Software):# Fakkeenya: System update gochuuf
sudo apt update && sudo apt upgrade
Tajaajiloota fi Hojiiwwan Sistemia To'achuu (Managing System Services)
Akka ROOT Guutummaatti Seenuu Hin Barbaachisu (Avoiding Direct Root Access)
sudo su (swich user) Of-eeggannoo: Root ta'uudhaan ajaja ajajju hundumaa irratti kompiutarri kee gaaffii malee raawwata. Fakkeenyaaf, faayilii sistemichaa balaan delete yoo gochte si hin dhorku. Kanaafuu, hojii root barbaadu xumurtan daftee exit gochuun filatamaa dha.
